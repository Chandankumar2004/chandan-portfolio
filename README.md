# Chandan Kumar | Full-Stack Developer Portfolio

A responsive portfolio showcasing full-stack work, client projects, skills, experience, and freelance services.

## Highlights

- Interactive skills, project, experience, freelance, and contact sections
- Live projects including Cadiefy, AR SAURTECH Energy, Delhi Explorer, and KodJobs
- Responsive layout for phones, tablets, laptops, and large screens
- Formspree contact form with client-side validation and success/error feedback
- Lazy-loaded 3D Earth model in the contact section

## Built with

React, Vite, Tailwind CSS, Framer Motion, GSAP, React Three Fiber, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```
